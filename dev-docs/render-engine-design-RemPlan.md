# Render Engine Design — Remediation Plan

**Status:** Round 1 NO-GO; one consolidated correction planned. This plan covers the settled renderer design at `e168ecd815df679202cfd4bc60b9330df64e5305` and root architecture at `a8f88fdbda3108005166a75545cc6c6b7ef5e2d4`.
**Reviews:** [Consistency](render-engine-design-ReviewConsistency.md) and [Safety](render-engine-design-ReviewSafety.md), both filed verbatim. Each found only P2 blockers. Both independently found the missing restart-recovery rule.

| Axis / finding | Disposition and correction | Closure evidence required |
| --- | --- | --- |
| Consistency P2-1, preview ownership | Accept. Record an ADR superseding the architecture's UI layer-composition path; update AD-01/AD-07, component ownership, diagrams and preview flow. The Preview service supplies one composed resource; the UI presents it and applies display-only transforms. | A two-layer sequence returns one leased composite resource, and the architecture and UI design agree on who composes it. |
| Consistency P2-2, offline authority | Accept. Split request provenance into governed-host and standalone-import contexts. Only the host context carries a project-open authority incarnation. A validated portable graph/binding manifest has local import identity and no host authority claim. | Offline package renders without Glade; it produces the same semantic plan as the same graph and bindings in a governed host, while evidence distinguishes provenance. |
| Consistency P2-3, binding identity | Accept. Include the binding-set ID and revision in every bound consuming request/result and its artifact-use record. Separate the consuming identity from a reusable content-addressed subresult key; validate all contributing slots before mapping reuse across sets. | Same-byte, changed-byte and unrelated-slot rebinds produce distinct consuming contexts, correct cache misses and verified unaffected reuse. |
| Consistency P2-4, hardware fallback | Accept. Treat fallback as a new planned attempt with a new provider manifest and recalculated task/dependent artifact keys. The failed attempt cannot publish or seed the successful cache entry. | Inject failure after Prepare and check actual provider/build in every downstream key, export record and probe. |
| Consistency P2-5 and Safety P2-3, restart | Accept as one shared root cause. Give Glade and local CLI supervisors durable job/temporary-artifact ownership records, startup reconciliation, orphan-process handling and explicit interrupted/failed states. Reuse only verified work; preserve the prior final destination. | Crash at staging, intermediate, verification and publication boundaries; restart either cleans or safely resumes and reports terminal status. |
| Safety P2-1, missing export wire | Accept. Add a versioned Taut ExportJobs request/ack, event log, status and cancel contract with pinned context, opaque destination, authorization rule, event sequence/replay and recovery semantics. Regenerate bindings and add wire/semantic fixtures. | Two concurrent exports with different revisions/bindings, out-of-order events, one cancellation and stale result after reopen are rejected or correlated correctly across languages. |
| Safety P2-2, profile drift | Accept. Resolve a named profile to an immutable version and definition digest at admission; carry effective settings through workflow, cache, verification, result and export record. | Change profile between prepare/run and retry; old request uses its pinned definition or fails clearly. |
| Safety P2-4, resource overrun | Accept. Specify measured-use accounting and enforceable per-job/aggregate limits for native processes, queues and artifact sinks, plus pause/terminate/capacity status when a grant is exceeded. | Understated decode memory and output size cannot starve interactive frame work or grow unbounded. |

The correction is one patch across the renderer design, Taut schema/generated bindings and contract tests, and the root architecture/ADR. The shared wire and preview architecture change means round 2 requires fresh, peer-blind Consistency and Safety reviewers on the new settled tuple. Reports and this plan are evidence, not independent acceptance.
